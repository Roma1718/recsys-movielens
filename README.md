# MovieLens Recommendation System

Pet-проект рекомендательной системы на датасете MovieLens 100K.

## Задача

Цель проекта — по истории оценок пользователя сформировать Top-10 фильмов, которые он с наибольшей вероятностью оценит положительно.

Проект сделан как практическая работа по ML и рекомендательным системам: от подготовки данных и baseline до обучения модели и оценки качества.

## Что сделано

- загрузка MovieLens 100K;
- очистка и подготовка пользовательских оценок;
- временное разделение данных на train и test;
- baseline на основе популярности фильмов;
- построение user-item matrix;
- обучение модели `TruncatedSVD`;
- исключение уже просмотренных фильмов;
- формирование Top-10 рекомендаций;
- сравнение модели с baseline;
- оценка через `RMSE`, `Precision@10` и `Recall@10`.

## Почему temporal split

Для каждого пользователя оценки сортируются по времени. Более ранние взаимодействия используются для обучения, более поздние — для проверки.

Такой способ лучше отражает реальную ситуацию: модель получает прошлую историю пользователя и должна рекомендовать то, с чем он взаимодействует позже.

## Запуск

Установить зависимости:

```bash
pip install -r requirements.txt
```

После этого открыть проект в VS Code и запустить:

```text
src/train.py
```

При первом запуске MovieLens 100K скачивается автоматически с GroupLens.

После выполнения создаются:

```text
artifacts/metrics.json
artifacts/top_recommendations.csv
```

## Метрики

`RMSE` показывает ошибку прогноза рейтинга.

`Precision@10` показывает, какая доля из десяти рекомендованных фильмов оказалась релевантной пользователю.

`Recall@10` показывает, какую долю релевантных фильмов из test модель смогла найти в первой десятке рекомендаций.

Также метрики модели сравниваются с baseline по популярности.
