# Что рассказать на собеседовании

Проект строит рекомендации фильмов на MovieLens 100K.

Логика работы:

1. Загружаются пользовательские оценки фильмов.
2. Для каждого пользователя данные сортируются по времени.
3. Более ранние оценки идут в train, более поздние в test.
4. Из train строится матрица user-item.
5. TruncatedSVD находит скрытые факторы пользователей и фильмов.
6. Уже просмотренные фильмы исключаются из рекомендаций.
7. Качество сравнивается с baseline по популярности.
8. Используются RMSE, Precision@10 и Recall@10.

Важно уметь объяснить:

- почему нельзя оценивать recommender только по RMSE;
- зачем нужен baseline;
- почему временной split лучше случайного для такого проекта;
- чем Precision@10 отличается от Recall@10;
- что такое user-item matrix;
- что делает SVD.
